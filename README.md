# AI 제주정책 보부상

AI 제주정책 보부상은 제 개인 업무의 보조 성격으로 만든 데이터베이스였으나,
이를 공익 목적으로 제주 도민과 공직자분들께도 도움이 되었으면 해서 오픈하는
**개인 무료 공익 서비스**입니다.
최대한 **도정·정부 정책, 공공지원사업, 법령·조례, 의정활동, 행정 용어**를
한 화면에서 찾을 수 있게 만드는 중입니다.
광고·수익모델·유료화가 없으며, 예산 0원으로 공공데이터와 오픈소스만으로 운영합니다.

- **서비스 주소:** https://kokoom94-ai.github.io/mondak/
- **성격:** 비영리 공익 · 개인 제작 · 참고용
- **원칙:** 공식 자료를 대체하지 않으며, 언제나 원문·출처로 안내합니다.

## ✦ 정책 미리내 — 이번에 새로 담은 것

**정책 미리내**는 정부의 국정과제와 제주의 공약이 어떻게 이어지는지를
밤하늘의 은하수(미리내)처럼 3D로 보여 주는 정책 연계 지도입니다.
정책비서 화면 안에서 볼 수 있고, 전체화면으로도 열립니다.

- **정부 정책 미리내** — 이재명정부 123대 국정과제
- **제주 정책 미리내** — 제주 민선9기 100대 정책과제
- 두 은하를 **의미 기반으로 연계**(89건 연결)하고, 제주가 앞서가는 **고유 정책 11건**은 따로 빛나게 표시
- 각 과제를 누르면 **목표·이행계획·기대효과**와 **연계 국정과제** 세부내용까지 확인
- 은하수 구조가 낯선 분을 위해 **「표로 한눈에 보기」** 도식(매핑표) 제공 — 표에서도 눌러서 세부내용 확인
- PC는 3D 시각화, 모바일은 구조화된 리스트로 자동 전환

> 「정책 미리내」의 연계는 **관리자가 정부·제주 정책을 자체 분석·정리한 참고 자료**이며,
> 공식 발표 자료가 아닙니다. 공식 정책자료는 각 정부 및 도청 누리집을 참고해 주세요.

## 참고·연계·활용한 자료와 기술

이 서비스는 아래의 공공데이터·오픈소스·참고자료를 바탕으로 만들었습니다.

### 공공데이터 · 정책자료
- **법제처 국가법령정보센터** — 제주 관련 법령·조례·규칙 (원문 링크 연결)
- **정부 123대 국정과제** 및 **제주 민선9기 100대 정책과제** 공식 발표자료 (미리내 데이터 기반)
- **기업마당·공공기관 공고** — 공공지원사업 정보 (주목합써)
- **국회·제주도의회 의정 정보** — 의원 활동 (동네의원)
- **Open-Meteo** — 날씨 정보 (오픈 API)
- **Google News RSS** — 뉴스 수집 (제목·출처·링크만 저장)

### 오픈소스 · 라이브러리
- **Three.js** — 정책 미리내 3D 시각화 렌더링
- 순수 HTML/CSS/JavaScript 단일 파일 구조 (별도 서버·빌드 불필요)

### 참고한 작업
- **대한민국 제도 온톨로지 뷰어(류주임)** — 정책을 별과 은하로 시각화하는 아이디어를 참고했습니다.
  (구조·데이터·구현은 제주 정책에 맞게 새로 제작)

> API 키·비공개 엔드포인트 등 민감정보는 저장소에 포함하지 않습니다.

## 저장소 구성
| 경로 | 역할 |
|---|---|
| `index.html` | 보부상 본체 (단일 파일 웹앱) |
| `mirinae3d.html` | 정책 미리내 — 3D 정책 연계 시각화 (정책비서에서 임베드) |
| `data/laws.json` | 제주 법령·조례 데이터 |
| `data/news.json` | 뉴스 수집 결과 (분야별 분류) |
| `data/assembly.json` · `data/council.json` | 국회·도의회 의정 데이터 |
| `data/stats.json` | 통계 데이터 |
| `scripts/collect_news.py` | 뉴스 수집기 (표준 라이브러리만 사용, API 키 불필요) |
| `.github/workflows/` | 뉴스 자동 수집 (GitHub Actions) |

## 배포 (GitHub Pages)
1. 이 저장소를 `main` 브랜치에 푸시
2. Settings → Pages → Branch: `main`, 폴더 `/ (root)`
3. 잠시 후 `https://kokoom94-ai.github.io/mondak/` 에서 확인

> `mirinae3d.html`은 반드시 **저장소 루트**에 두어야 정책비서 안 미리내가 정상 표시됩니다.

## 데이터 정직성 원칙
- 기관 전화번호는 검증 통과분만 직통 표기, 미확인은 대표번호 경유 안내
- 시연 수치에는 항상 '시연' 표기, 수집 연동 시 배지가 수집 시각으로 바뀜
- 뉴스는 원문 링크로 연결하며 제목·출처만 저장 (본문 미복제)
- 정책 미리내의 연계는 관리자 자체 분석 결과로, 공식 자료가 아닌 참고용임을 명시

보부상은 그 정보를 한 자리에 모아, 누구나 쉽게 찾고 이해하도록 돕기 위해 만들었습니다.
