# 몬딱 — 제주 정책·민원 데이터베이스

> 공무원에게는 정책비서·제주위키가 있습니다. **몬딱은 그 도민판입니다.**

제주 도민이 도정·행정시·읍면동·도의회의 정책과 지원사업, 기관 연락처, 행정 용어를
한 화면에서 찾게 하는 **개인 운영 무료 공익 서비스**입니다. 광고·수익모델이 없습니다.

## 구성
| 경로 | 역할 |
|---|---|
| `index.html` | 몬딱 본체 (단일 파일 웹앱) |
| `urido-alrimi.html` | 우리 동네의원 알리미 — 도의원 45인 · 선거구 지도 |
| `data/news.json` | 새소식 데이터 (자동 수집 결과) |
| `scripts/collect_news.py` | Google News RSS 수집기 (표준 라이브러리만 사용, API 키 불필요) |
| `.github/workflows/collect-news.yml` | 하루 3회(KST 06/12/18시) 자동 수집 |

## 배포 (GitHub Pages)
1. 이 폴더를 저장소로 푸시
2. Settings → Pages → Branch: `main`, 폴더 `/ (root)`
3. Actions 탭 → `collect-news` → **Run workflow** (첫 수집 수동 실행)

## 데이터 정직성 원칙
- 기관 전화번호는 검증 통과분만 직통 표기, 미확인은 대표번호 경유 안내
- 시연 수치에는 항상 '시연' 표기, 수집 연동 시 배지가 수집 시각으로 바뀜
- 뉴스는 원문 링크로 연결하며 제목·출처만 저장 (본문 미복제)
